# Medical Writing assistant

Open **this folder** in Cursor when you want the medical writing bot.

## Skills

| Skill | Use it for |
| --- | --- |
| `/copy-deck` | Build a copy deck from a brief + approved claims |
| `/fact-check` | Verify draft wording against the claim bank |
| `/reference-claims` | Attach footnotes/refs from the claim bank |
| `/editorial-pass` | Style/clarity edits without changing approved claim meaning |

## Quick start

1. **File → Open Folder…** → `medical-writing`
2. Update `claims/claim-bank.md`, `references/reference-library.md`, and `style/style-guide.md`
3. Copy `drafts/brief-template.md` for a new piece
4. In Agent chat, type `/` and run a skill

## Suggested flow

1. `/copy-deck`
2. `/fact-check`
3. `/reference-claims`
4. `/editorial-pass`

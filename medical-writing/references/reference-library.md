## Field guide

- **Reference ID:** Stable unique ID
- **Citation:** Final formatted citation in house style
- **Linked claim IDs:** Claims that are allowed to use this reference
- **Document type:** Journal, PI, congress abstract, data on file, etc.
- **Status:** Approved / Retired / In review

## Tips

- Prefer one canonical citation string per reference
- If a claim has multiple references, list all IDs on the claim row and keep each reference here
- Never invent DOIs, authors, or years to fill gaps

# Trading Journal assistant

Open **this folder** in Cursor when you want the trading journal bot.

## Skills

1. `/rename-screenshots`
2. `/green-reviews`
3. `/red-reviews`

## Quick start

1. **File → Open Folder…** → `trading-journal`
2. Put screenshots in `inbox/` (or set a path in `config.md`)
3. In Agent chat, run:
   1. `/rename-screenshots`
   2. `/green-reviews`
   3. `/red-reviews`

## Rename format

`Date_Trade X_Direction_Playbook_Green/Red`  
Example: `2026-09-28_Trade 1_Long_ORB_Green.png`

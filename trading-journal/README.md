# Trade Journal assistant

Simple Cursor workspace for trading screenshots.

## Skills

1. `/rename-screenshots`
2. `/green-reviews`
3. `/red-reviews`

## How to use

1. Merge the PR if needed, then pull `main`
2. **File → Open Folder…** → open `trading-journal`
3. Put screenshots in `inbox/` (or set a path in `config.md`)
4. Run the skills in order:
   1. `/rename-screenshots`
   2. `/green-reviews`
   3. `/red-reviews`

## Rename format

`Date_Trade X_Direction_Playbook_Green/Red`  
Example: `2026-09-28_Trade 1_Long_ORB_Green.png`

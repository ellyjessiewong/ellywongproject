# Local screenshot folder (optional)

If your screenshots live somewhere else on your computer, paste the full path below.
When you run `/rename-trade-screenshots`, the assistant will use this path if `inbox/` is empty.

## Local path

```text
PASTE_FULL_FOLDER_PATH_HERE
```

Examples:
- macOS: `/Users/elly/Pictures/TradingScreenshots`
- Windows: `C:\Users\elly\Pictures\TradingScreenshots`

## Notes

- Easiest path: copy or move screenshots into `inbox/` in this workspace.
- If you use Grok Bot with local execution instead, see `GROK_BOT_SETUP.md`.

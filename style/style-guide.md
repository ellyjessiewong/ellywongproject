# House style guide (starter)

Customize this to match your agency / client style. Skills read this file during drafting, referencing, and editorial passes.

## Voice and tone

- Clear, professional, compliant
- Prefer concise sentences
- Do not add hype words around approved claims

## Product and trademark

- Use the approved product display name consistently
- Follow client trademark / ® / ™ rules (add them here)
- Spell out the drug/molecule name on first use if required

## Spelling and mechanics

- Locale: US English (change if needed)
- Numbers: follow house preference (e.g. spell out one–nine in running text)
- Abbreviations: define on first use unless universally known in the audience

## Claims and footnotes

- Prefer exact approved claim wording from `claims/claim-bank.md`
- Every substantive claim needs claim ID + reference IDs
- Citation markers: use bracketed numbers like `[1]` unless client requires another style
- Reference list: numbered in order of first appearance

## Fair balance / mandatory language

- Do not invent ISI, ISI-like, or fair-balance language
- If the user provides approved mandatory text, keep it visually separate from promotional body copy
- Flag missing mandatory language when the channel normally requires it
